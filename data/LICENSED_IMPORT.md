# Licensed external imports

`quotes.licensed.json` may contain only manually curated records. The build rejects every record without a HTTPS source URL, a license URL, a rights jurisdiction, the author's death year and `verificationStatus: "verified"`.

Allowed licenses: `CC0-1.0`, `CC-BY-4.0`, `PUBLIC-DOMAIN`. Do not enter Goodreads content, unlicensed web text or modern translations. For `PUBLIC-DOMAIN`, the 70-year author-death rule is an internal German/EU review baseline; the source and jurisdiction must still be checked per work.
